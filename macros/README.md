# FluidDial: Optional macro examples for new MPG menu

These macros needs to be put on FluidNC itself, in the flash storage (local storage or localFS).
The new MPG menu will be looking for these macros under macros/ folder, and the file names have to be exactly like they are in this example folder.

DISCLAIMER! These macros are only examples, and have predefined offsets for the probes used by the author, and may not work at all for your use case and machine setup. You can modify them if it suit your needs.
